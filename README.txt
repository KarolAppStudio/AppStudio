# Christadelphian Apps Website

A self-contained, responsive static website for KarolAppStudio's Bible reading applications.

## Contents

- `index.html` – main page
- `css/styles.css` – all site styling
- `js/script.js` – minimal progressive enhancement
- `assets/favicon.svg` – lightweight favicon

## Deploy

1. Extract the ZIP.
2. Upload the contents of this folder to your hosting space's public web root (`public_html`, `www`, `htdocs`, etc.).
3. Open the domain in a browser.

No build step, package manager, database, PHP, Node.js, or server-side framework is required.
